## 3. V3.2 atomicity is preserved, not weakened

Exactly the existing categories remain:
`SEMANTIC_PRIMITIVE`, `GENERIC_CONSTRUCT`, `API_DECODER`, `ATOMIC_OPERATOR`, `VALUE_OR_LITERAL`, `OUTPUT_CATEGORY`, `ATOMIC_CONTROL_DATAFLOW`.

A task-essential atomic capability is one task-essential typed NODE with its frozen local operation/type/role semantics, or one task-essential occurrence of one of the ten frozen directed typed EDGE relations. Every such occurrence must have its own actual typed selector/requirement correspondence. Reusable capability identity may be shared; occurrence satisfaction, multiplicity and attachment obligations may not be erased.

The ten labels remain:
`INPUT_TO_DECODER`, `VALUE_TO_PREDICATE`, `PREDICATE_TO_CONTROL`, `PREDICATE_TO_INDICATOR`, `VALUE_TO_OPERATOR`, `OPERATOR_TO_ACCUMULATOR`, `CONTROL_TO_UPDATE`, `LOOP_CARRY`, `PRIOR_STATE_TO_UPDATE`, `ACCUMULATOR_TO_OUTPUT`.

The fixed domain decoder is an **additional** closed interface macro. It requires INPUT and, for arrays, SPLIT, four connected TO_NUMBER calls and the four indexed decoded values, together with schema/class evidence. It neither subsumes nor erases task-essential constituent nodes/edges. Macro evidence cannot satisfy a missing constituent selector; constituent evidence cannot satisfy the macro. Its inherited capability-level quantification does not demand a different witness for every conversion occurrence.

An emitted task-essential INPUT_TO_DECODER, VALUE_TO_PREDICATE or VALUE_TO_OPERATOR edge is atomic, including constant-bearing and internal decoder relations. The same rule applies to every other emitted task-essential frozen edge label. No demotion is permitted because intervention is inconvenient, an adjacent selector exists, the macro exists, a value is constant, a relation is internal, or activity is difficult.

Contextual records may remain mandatory non-atomic support **only when they do not themselves instantiate a typed V3.2 NODE/EDGE**. Examples are phase/order records, attachments, state-view metadata, static provenance/binding associations and prerequisite wrappers. If a future reviewed representation instead emits an actual typed state-view, carrier, binding or other V3.2 node/edge, normal atomicity and the applicable evidence class below apply. A record's name does not decide this boundary.

This proposal chooses no concrete graph representation or selector instance. Later representation decisions must preserve required semantic operations and dependencies, with positive clause-owned essentiality, actual typed matching, static multiplicity and attachments. Moving a genuinely atomic operation into an attachment merely to escape its obligation is prohibited.

## 4. Total evidence-class binding before candidate generation

Every task-essential atomic key must bind **exactly one** scientific evidence class before candidate generation, source/case acceptance or scientific execution. Binding uses category, actual node/edge operation, payload/result type, destination role and whether the operation is an accumulator-contribution update. It cannot use condition label, task ID, observed activity, witness, acceptance result or historical implementation.

The following selection precedence is exhaustive and disjoint:

1. OUTPUT_CATEGORY → output-attribute evidence (§12).
2. VALUE_OR_LITERAL → the appropriate fixed-value/lexeme or runtime-value-role attribute class (§8). No attribute-specific mutation.
3. API_DECODER → its exact INPUT/domain, SPLIT or numeric-API class (§5).
4. A behavioral accumulator-contribution writer or OPERATOR_TO_ACCUMULATOR/accumulator-role CONTROL_TO_UPDATE → contribution suppression, not ordinary numeric replacement.
5. A behavioral control node or Boolean decision-use edge → exact Boolean result/decision-destination replacement.
6. A behavioral typed result, read/view, indexed result, non-accumulator write or directed payload → the exact type/role replacement in §§5–9.
7. Final display → displayed-integer-argument replacement, not replacement of UNIT.

Steps 4–7 are distinguished by the pre-bound semantic operation/role; final display is not a typed value-returning operation under step 6. Matching several incompatible roles, matching none, or an unknown operation/type is unresolved and blocks construction. A typed node with statement result UNIT uses its specified decision, written value or display-argument activity site, never an untyped UNIT neutral.

For the already-certified local pair-joint semantic-result relation, the existing relation marker selects J after category/attribute/API separation and before the general result rules. That marker cannot be attached to an independent operator ability or another edge to change its evidence class or coverage scope. Its BOOL/INDICATOR_INT source refinement is fixed by the permitted local certificate, never by a trial result.

`SCIENTIFIC_INTERVENTION_CLASS_MISSING` means missing scientific authority and fails closed; it is not a programming ticket. `MAPPING_NOT_YET_BUILT` means a scientifically defined class exists but its exact IR/source binding or engine has not yet been implemented. The latter may remain later work in this proposal, but prevents candidate generation until the required reviewed/frozen mapping and engine exist. An implemented but untypable/unexecutable intervention remains UNRESOLVED/FAIL. Neither label authorizes execution here.

Attributes have exactly one scientific **evidence** class, not a behavioral mutation. Thus the total-class requirement does not resurrect independent VALUE_OR_LITERAL or OUTPUT_CATEGORY mutations.

## 5. Closed typed replacement classes and retained interventions

Types describe semantic payloads, not a new gate category or permission to introduce operations. The closed scalar/structured payload universe required by the current grammar is BOOL, INT, INDICATOR_INT, TEXT, TEXT4 and INT4. Numeric indices, bounds, steps, counts, offsets and pre/post/completed numeric states retain INT roles; INDICATOR_INT refines INT to 0/1. TEXT roles distinguish a numeric field, a serialized numeric input, a raw four-field array input and the fixed decoder separator. TEXT4/INT4 have exactly four ordered fields. UNIT is a statement result/context marker, not a payload carried by any of the ten scientific edge relations.

| Class notation | Exact ordered intervention | Activity site / scope |

| F | text "0", then text "1" | Exact single signed-integer field or serialized scalar-numeric TEXT destination before decoding |

## 9. Control/dataflow, state and intervention locality

Contribution suppression overrides numeric/Boolean replacement only for the specified accumulator-contribution site. It removes every contribution of the selected key's mapped update instances while retaining each prior accumulator state. It is not suppression of a state initialization, a prior-state read, an index step or an entire phase.

CONTROL_TO_UPDATE to an indicator reset/set, ordinary assignment/initialization or required index/control writer uses B at its own decision-consumption site. The intervention does not force an unrelated sibling writer's decision merely because both originate in the same IF or loop. A selected control NODE, by contrast, acts at its own decision and therefore retains that node's real downstream effects. These are distinct actual selectors with existing Boolean intervention meaning.

Numeric PRIOR_STATE_TO_UPDATE/LOOP_CARRY replace only the exact read/carry destination value by 0/1, retaining state identity, PRE/POST view, phase membership and the other mapped definitions. An actually emitted state-view NODE has the corresponding typed read class; purely contextual state-view metadata has no selector or mutation.

A genuinely required stored decoder field/package read represented as an actual NODE uses F/A/T4/I4 by its exact TEXT/structured role, or C for a separately emitted fixed-separator read. This does not create a text/package accumulator or permit structured payloads on numeric carry/prior edges. It closes read-node typing if such storage is represented explicitly; otherwise a mere definition/view association remains contextual under §3.

The full graph must still preserve strict PREFIX PRE use and result-before-P update, both carries, and completed output; TWO_PASS retains two complete P-first/Q-second phases, Q initialization at phase-2 entry, immutable completed-P persistence and multiplication/output after both completions. No phase deletion, reordering, loop fusion, product-to-sum rewrite, per-occurrence test or special final-item mutation is permitted.

Changing an edge value may change subsequent behavior; that is a counterfactual consequence, not a changed normal target. Original normal source/reference correctness remains E1's responsibility. No global array reordering, parser-configuration rewrite, artificial loop clamp, bounded replay or termination waiver is allowed. If an allowed intervention cannot be typed or executed, frozen UNRESOLVED/FAIL applies. Defining a class is not proof of future activity or candidate feasibility.

## 10. Normal events and frozen witness quantification

Every BEHAVIORAL class requires all three:

1. an exact connected parsed source-to-contract path that executes on one of that example's five frozen cases and reaches displayed computation;
2. a normal-run nonzero contribution or selection of an executed nonzero update on that path;
3. an allowed capability-level counterfactual changing the correct final output on a case with that normal event.

For decoder, structured payload, scalar operand, indexed result, prior-state, carry, initialization and state-view roles, execution/consumption must be demonstrated on the particular mapped path to that normal event. A payload need not itself be nonzero: a required threshold or prior zero may participate in a genuine nonzero update. Merely executing elsewhere in a program with a positive total is insufficient. Dead overwritten definitions, disconnected fields and algebraically cancelled paths cannot qualify from a hypothetical changing replacement.

Normal-event attribution follows the selected role's actual contribution or selected update. A false predicate's zero indicator contribution cannot borrow another predicate's nonzero independent contribution through a shared final accumulator. Conversely, a zero threshold or prior-state payload can participate in its own genuinely nonzero mapped update. The evidence must establish that distinction from the normal computation, before any forced value; global output positivity alone proves neither activity nor event attribution.

For a non-accumulator control/writer role, the normal execution of its particular assignment/reset/index write must lie on the connected path selecting/producing that nonzero update. A false branch with no such event is not rescued by forcing true. For the final display and final-output edge, the normal event is the actual nonzero integer emitted by the required display on that same mapped computation. A zero-only display does not become active solely because overriding it to 1 changes an artificial output. This nonzero display-event completion is explicitly prospective, not an assertion of a previously complete generic-output rule.

Initialization may have its legitimate normal downstream update event after the initialization; an empty numeric traversal does not acquire a decoder or loop-body activity event just because a fixed offset is displayed. The frozen INPUT_DOMAIN class and activity witnesses may still be different cases in the same example, exactly as its amendment permits. The additional 14 domain-class obligations remain unchanged.

For one key in one example, intervene on **all mapped instances of that key together**. This includes every dynamic execution of its mapped static sites, preserving the complete static inventory, role/phase identity and joint quantification. Do not select only a convenient occurrence, phase, operand, field or last iteration. The number of loop executions is not static occurrence multiplicity.

Retain the lexicographically first qualifying frozen case and, within it, the first successful intervention in the class's listed order. Contribution suppression has one trial. Attribute/output witnesses retain their inherited ordered-case selection and do not become counterfactuals. An unavailable, malformed, untypable or unexecutable required intervention is unresolved and blocking; neither an earlier success nor a timeout waiver repairs it. Implementation must later freeze/test exact class semantics before candidate generation. No testing or evidence execution is authorized here.
